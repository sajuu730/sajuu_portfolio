PROJECT 02 / RELIABILITY & OPERATIONS

Making connector failures easier to see and investigate.

A Spring Boot service that polls Kafka Connect, detects failed connectors and tasks, classifies likely causes and exposes operational metrics—with recovery deliberately disabled by default.

01 / SYSTEM OVERVIEW

Observe first. Recover cautiously.

Ops Guardian connects to the Kafka Connect Distributed REST API, checks connector and task states, and turns detected failures into structured incident signals. It adds Prometheus metrics and an optional guarded task-restart path so operational automation has explicit safety boundaries.

02 / ENGINEERING HIGHLIGHTS

What the system demonstrates.

01

Connector and task checks

Polls connector inventory and status endpoints, including connector-level FAILED state even when no task details are returned.

02

Failure classification

Uses lightweight heuristics to map observed failure text into likely categories for faster initial triage.

03

Guarded recovery

An opt-in task restart path is protected by a process-local rolling-window circuit breaker. Recovery is disabled by default.

04

Operational metrics

Publishes health and failure-related metrics for Prometheus-based monitoring.

05

Webhook notifications

Can publish incident notifications with bounded retry behavior; without a configured webhook, events are logged.

06

Container and deployment assets

Includes a Docker image and Kubernetes deployment/service/configuration examples.

04 / SCOPE & LIMITATIONS

What this project does—and doesn't claim.

This is an early-stage portfolio implementation. Its emphasis is status monitoring, failure visibility and safe defaults—not autonomous remediation or a complete enterprise incident platform.

  • Failure classification is heuristic and should be treated as a triage hint, not a definitive root-cause analysis.
  • Restart budget is process-local; run a single replica while recovery is enabled unless distributed coordination is added.
  • No stalled-task detection, durable incident outbox, webhook authentication/signing or whole-connector automatic restart.
  • Broad production-scale integration, resilience and security validation has not been claimed.

For implementation details, setup instructions, tests and current limitations, see the repository documentation.
