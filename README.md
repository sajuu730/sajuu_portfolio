# Sajid Manzoor — Portfolio Website

A responsive, single-page engineering portfolio built with HTML, CSS and vanilla JavaScript.

## Sections

- Animated scroll reveals and subtle motion effects
- Dedicated case-study pages for each featured project
- Architecture flow diagrams and clearly labelled synthetic demo panels

- Introduction and engineering focus
- About and independent portfolio-project context
- Three featured GitHub projects
- Technology toolkit
- Contact links

## Run locally

Open `index.html` in a browser, or start a simple local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)` folder, then save.
4. Wait for the Pages deployment workflow to finish. The site URL will be shown in Settings → Pages.

## Customization

- Update the profile copy and links in `index.html`.
- Adjust colors, typography and layout in `styles.css`.
- Mobile navigation and footer year are handled in `script.js`.

All featured repositories are independent portfolio demonstrations. Their README files document implementation scope and limitations.
